## 这是什么

一个把「路演录像」变成「可执行改进清单」的方法。

输入：一段路演/演讲/比赛录像（或笔记）。
输出：分段的评分 + 具体改法 + 下一版该怎么讲。

## 拆解结构

一场路演按顺序过五段，每段单独评：

| 段 | 要回答的问题 | 常见毛病 |
|---|---|---|
| **开场** | 30 秒内让人知道你在解决谁的什么问题 | 从公司介绍讲起 |
| **问题** | 这个问题有多痛、多普遍 | 讲行业不讲具体的人 |
| **方案** | 你的做法和别人的区别在哪 | 罗列功能不讲取舍 |
| **证明** | 凭什么信你能做成 | 只有愿景没有数据 |
| **收尾** | 你想让对方做什么 | 「谢谢大家」就结束 |

## 评分口径

每段三档：**能过 / 需改 / 不过**。

判据不是「讲得好不好听」，是「不知道背景的人听完，能不能复述出这一段的核心」。

## 输出样例

```
开场      需改   前 40 秒在讲公司成立于哪年，没说是给谁解决什么
问题      能过   痛点讲得具体，有真实案例
方案      不过   列了六个功能，没说为什么是这六个、砍掉了什么
证明      需改   有一个客户案例但没量化效果
收尾      需改   结尾是大纲式总结，没有明确的下一步请求
```

## 适用场景

- 黑客松 / 创业比赛路演
- 融资 pitch
- 产品发布会演讲
- 公开课、行业分享的录像复盘

## 不适用

单纯剪辑或制作视频，那是另一条链路。这个只管「讲的内容与结构」。
